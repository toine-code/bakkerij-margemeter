Het bakkerijsysteem op je eigen computer

Groter dan de margemeter, en dichter bij hoe het echt werkt in je bakkerij: je grondstoffen met de prijs per 100 kg van je leverancier, je recepten op bakkerspercentage, je voorraad in partijen zodat het rekent met de zak bloem waar je nu echt uit bakt, en de marktnoteringen voor tarwe, rogge, boter en suiker die het systeem zelf ophaalt bij de Europese Commissie.

  1. Download het pakketGebruik de knop hierboven en pak het bestand uit, bijvoorbeeld op je bureaublad.
  2. Dubbelklik de startknopOp een Mac Start bakkerijsysteem.command, op Windows Start bakkerijsysteem.bat. De eerste keer duurt het een halve minuut.
  3. Je browser gaat vanzelf openEr blijft ook een zwart venster openstaan, dat hoort zo. Sluit je dat, dan stopt het systeem.
  4. Zet je eigen cijfers erinIn het tabblad Je eigen cijfers zet je je facturen of je receptenboek neer en vraag je Claude Code om het systeem bij te werken. Of je vult de lijsten zelf in Excel in.

Er is Python 3 voor nodig. Op een Mac staat dat er al. Op Windows haal je het eenmalig op bij python.org, en vink je bij het installeren "Add Python to PATH" aan. De eerste keer waarschuwt je computer dat het bestand van internet komt: op een Mac klik je met rechts op de startknop en kies je Openen, op Windows klik je op Meer informatie en dan Toch uitvoeren.

Vier dingen om te weten
  • De cijfers die er nu in staan zijn voorbeelden. Ze zijn plausibel gekozen, maar het zijn niet jouw cijfers tot je ze vervangt.
  • Het rekent wat jij invult. Controleer de eerste tabel een keer met de hand.
  • Alles blijft op je eigen computer. Je recepten en prijzen gaan nergens heen. Alleen de marktnoteringen komen binnen, en alleen als je op die knop drukt.
  • Het is geen boekhouding. Overleg met je accountant voor je je prijskaart omgooit.
